# PromptBox — Android

Нативный Android-проект на Kotlin + Jetpack Compose.

## Возможности
- Локальное хранение промптов на устройстве (SharedPreferences + JSON).
- Добавление, редактирование и удаление.
- Поиск по названию, тексту и тегам.
- Категории и избранное.
- Копирование полного промпта в буфер обмена.
- Резервный экспорт и импорт библиотеки в JSON.
- Несколько демонстрационных промптов при первом запуске.

## Сборка APK
1. Установите Android Studio (версия с поддержкой AGP 8.7.3).
2. Откройте папку `PromptBoxAndroid` через **Open**.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/`.

Требуется JDK 17 и Android SDK Platform 35. Минимальная версия Android — 8.0 (API 26).

## Примечание
Данные хранятся локально на телефоне и не отправляются на сервер. Для переноса на другое устройство используйте экспорт JSON.
